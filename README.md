# 📊 Comparative Financial Performance Analysis of Top 5 Indian IT Companies

## 📌 Project Overview

This project performs an exploratory and comparative **data analytics study of the financial performance of five leading Indian IT companies**. The analysis uses historical financial data to identify trends, compare business performance, evaluate profitability, and understand how key financial indicators vary across companies and over time.

The project focuses on transforming raw financial data into meaningful insights using **Python, Pandas, NumPy, Matplotlib, Seaborn, and Exploratory Data Analysis (EDA)** techniques.

---

## 🎯 Objectives

* Analyze the historical financial performance of major Indian IT companies.
* Compare key financial metrics across companies.
* Identify revenue and profitability trends.
* Analyze year-over-year financial growth.
* Understand relationships between different financial indicators.
* Identify the strongest and weakest performing companies based on selected metrics.
* Present findings through meaningful data visualizations.

---

## 🏢 Companies Covered

The analysis includes five major Indian IT companies:

1. **Tata Consultancy Services (TCS)**
2. **Infosys**
3. **HCL Technologies**
4. **Wipro**
5. **Tech Mahindra**
